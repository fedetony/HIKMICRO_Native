## Tracker System

HIKMICRO Native includes a tracker system for visualizing historical probe data.

Each probe maintains a measurement history containing:

- Timestamp.
- Average temperature.
- Minimum temperature.
- Maximum temperature.

Tracker plots can display this information in real time.

Available tracker curves include:

- Average temperature.
- Minimum temperature.
- Maximum temperature.

Tracker configuration includes:

- Enable/disable state.
- Plot title.
- Line style.
- Line width.
- Individual curve colors.
- Calibration conversion.

Trackers operate in:

- Live camera mode.
- Virtual Camera mode.
- Recording playback.

Because tracker data is derived from probe history, historical information remains available when a recording is replayed later.

Tracker plots automatically update while measurements are acquired.
